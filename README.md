# Sistema de Gestión para Freelancers

Un sistema completo para la gestión de clientes, facturas y proyectos diseñado específicamente para freelancers y pequeños negocios.

## Características

- **Gestión de Clientes**: Almacena y gestiona información de tus clientes.
- **Gestión de Facturas**: Crea, edita y envía facturas profesionales.
- **Generación de PDF**: Exporta facturas en formato PDF.
- **Seguimiento de Pagos**: Controla el estado de tus facturas y recibe notificaciones de pagos pendientes.
- **Interfaz Intuitiva**: Diseño moderno y fácil de usar con Material UI.

## Tecnologías Utilizadas

### Frontend
- React.js
- Material UI
- React Router
- Axios
- jsPDF (para generación de PDF)

### Backend (Planificado)
- Node.js
- Express
- MongoDB
- JWT para autenticación
